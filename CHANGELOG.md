# Changelog

All notable changes to Note2Quiz will be documented in this file.

## 0.1.0 - 2026-06-01

### Added

- React + Vite + TypeScript frontend
- FastAPI backend
- SQLite persistence
- PDF, DOCX, PPTX, and TXT text extraction
- OpenAI-compatible AI client
- Demo mode when no `AI_API_KEY` is configured
- Study pack history
- Markdown export
- Backend tests and pytest configuration
- GitHub community files
